# Food & Motherhood

A personal website built with HTML and Tailwind CSS that showcases my passion for cooking and motherhood, along with my journey into coding.

## About This Project

This is a personal portfolio website that combines my love for homemade meals, motherhood experiences, and my growing skills as a frontend developer. The site serves as a digital space where visitors can explore recipes, read about motherhood tips, and follow my coding journey.

## Features

### Responsive Design
- Fully responsive layout that works seamlessly on desktop, tablet, and mobile devices
- Mobile-first approach with breakpoints for all screen sizes
- Optimized navigation for smaller screens with a hamburger dropdown menu

### Recipe Section
- Interactive recipe cards with hover effects
- Multiple recipe categories (Jollof Rice, Pancakes, Healthy Kids Snacks)
- High-quality images for each recipe
- Direct links to detailed recipe pages

### Motherhood Content
- Dedicated sections for motherhood experiences
- Mom Life Tips with practical advice
- Personal stories and insights about parenting

### Coding Journey
- Showcase of frontend development skills
- Learning progress and achievements
- Future goals as a developer

### Interactive Elements
- Smooth animations and transitions
- Hover effects on cards and links
- Mobile hamburger menu with dropdown animation
- Click-outside-to-close functionality for mobile menu
- Dark mode support (Tailwind dark mode toggle ready)

### Navigation
- Sticky header that stays visible while scrolling
- Smooth scrolling to sections
- Mobile hamburger dropdown menu with smooth animations
- Auto-close menu when clicking outside or selecting a link

## Technologies Used

- **HTML5** - Semantic markup and structure
- **Tailwind CSS** - Utility-first CSS framework for styling
- **JavaScript** - Interactive functionality for mobile menu
- **Responsive Design** - Mobile-first approach with media queries

## Getting Started

To view this project locally:

1. Clone the repository
2. Open index.html in your web browser
3. No build process required - pure HTML/CSS/JS

## Customization

This project is easily customizable:
- Change colors in Tailwind classes (search for `amber-`)
- Modify content in the HTML sections
- Add new recipes following the existing pattern
- Adjust breakpoints in the responsive classes
